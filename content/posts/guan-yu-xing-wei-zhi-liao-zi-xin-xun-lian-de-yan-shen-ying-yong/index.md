接着直接讲这三点吧，所谓的角色扮演模仿学习，正是在众多道教咒语中呈现的概念——例如最常见的"神变"就是这个道理，可以看作是"角色扮演"对吧

{{< message name="科胡特" date="1971-?-?" >}}人的核心自体有夸大、理想性、密友自体。{{< /message >}}

{{< message name="科胡特" date="1971-?-?" >}}夸大自体中，人需要从别人的反馈体验到自己的全知全能感，从而获得自信；在理想性自体中人需要有一个密切联系、强大有力的具体榜样形象；而在密友自体中人需要从与他人的镜面形象中给出认同感，从而反向肯定自己，获得自信。{{< /message >}}

{{< message name="我" date="2024-9-29" self="true" >}}密友自体也太抽象了……{{< /message >}}

{{< message name="茴香豆" date="2024-9-29" >}}密友自体是与儿童相似的自体客体，其可能会激活儿童内在产生一种"我与你如此相似"的感受，一如孪生兄弟般、像是"密友"的感觉。与天赋技能紧密联系。{{< /message >}}

---

来对应一下吧，夸大自体就像是下山实践，或是像原阳子每天写日记一样，去感受自己。

而理想性自体就很好懂，例如像密宗有所谓的"上师"、或是更泛义上讲的"师父"或是自己供奉的神等等。

密友自体我想了一下，有点像是修炼中那个陪伴自己的识神、内神等等；又或是我们讲的"元婴"之类的。
