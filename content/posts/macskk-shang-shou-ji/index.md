前篇说到 SKK，此篇只管装法与打法。依样画葫芦即可，不必通读，卡住了再回来翻。

一言以蔽之：别家输入法在猜你意思，SKK 只听你意思。

## 一、此物来历

SKK，全称 Simple Kana to Kanji conversion program。1987 年由东北大学的佐藤雅彦所作，原本栖身于 Emacs 中，后由社区接手，如今 Mac、Windows、Linux 乃至 Vim 上皆有传人。

名字也有讲究。SKI 组合子演算里，SKK 这个式子等于恒等函数 I：输进去什么，原样出来什么。作者的意思许是，输入法不该加以干涉，亦即我手写我口矣。

其与 Google、ATOK、苹果自带那几家的分别，只在一处：谁来断句分词。

- **别家**：引擎做形态素解析，再添上统计模型，去猜何处成词、何处起送り仮名。猜错了，摸摸鼻子回头改文节。
- **SKK**：词从哪起、送り仮名从哪起，由你按 Shift 指定。它只拿你给的读音去查字典。

故而 SKK 的结果是定的。输入相同，永远出同样的候补。字典是纯文本，可读可改，亦能拿去与人交换。

有个老例子：

- ここでは着物を… → kokodehaKimono
- ここで履物を脱いで… → kokodeHakimono woNuIdekudasai

kokodehakimono 这一串本身便有歧义，别家只能靠上下文去赌。在 SKK 里，Shift 按在哪，答案就在哪。落指便荡除一切歧义。

好处是一路从左写到右，如执笔写字，鲜有回头。

代价亦有三：Shift 按得勤，小指受累（第九节有解）；头一两周会稍不适应；还得知道送り仮名打哪开始。不过这事在手写时本就知道，只是未尝留意罢了。

## 二、状态有二先分别

全篇机要便在此节。

SKK 难，非是难在键多，难在它同时有两套状态，而不察者众。

若将两套认清辨明，余下再无艰处。

### 其一，输入模式，管罗马字输出什么字形

- **かな**：小写罗马字出平假名。回到此处按 ⌃J（Control + J），姑且唤作回家键。
- **カナ**：小写罗马字出片假名。按 q，在かな与カナ之间来回。
- **直接输入**：不转换，敲什么出什么。按 l（小写 L）。
- **全角英数**：出 ａｂｃ 这类全角字母。按 L（<b>大写，亦即按住 Shift 再按下 L</b>）。

记法：l 是 latin，小写即半角；L 大写即全角；⌃J 回家。

### 其二，变换状态，管眼前这段字走到了哪一步

- **无标记**：直出文本，不查字典（=无须选字）。
- **▽**：正在攒一段读音，预备拿去查。
- **▼**：已经查到，正在候补里挑。

两套各行其是。「かな + 无标记」就是直接打平假名；「かな + ▽」是在攒读音，预备变汉字。▽ 这个三角既是状态，也是读音的起点：它落在哪，读音就从哪算起。

## 三、安装 macSKK

Mac 上我用的是 macSKK，mtgto 以 Swift 重写，二〇二三年面世，至今仍勤于更新。下陈安装程序。

1. 去 GitHub Releases 下载 .dmg：<https://github.com/mtgto/macSKK/releases>
2. 打开 dmg，运行其中的 .pkg。惯用 Homebrew 的，一行便了：`brew install --cask macskk`
3. 打开「系统设置 → 键盘 → 输入法」，添上 macSKK 的「ひらがな」与「ABC」两个输入源。カタカナ、全角英数、半角カナ，均是可有可无。
4. 若列表里寻不见，或升级后不生效，退出登录再登回来。

装完先别急着打。此时一本词典也无，敲什么都变不出汉字。（本人当初在此踩坑，还道它是坏了。）

## 四、挂词典

SKK 的词库，是另挂上去的。

1. 到 <https://skk-dev.github.io/dict> 下载基础词典。无他缘由，则选 SKK-JISYO.L，海纳百川。.gz 压缩包不必解压，直接放进去便可。
2. 放入此路径：`~/Library/Containers/net.mtgto.inputmethod.macSKK/Data/Documents/Dictionaries`。路径太长寻不着，就在 macSKK 设置的辞書页点「Show Dictionaries in Finder」径直打开。
3. 切至 macSKK，点菜单栏的输入法图标进设置，在辞書页把刚放入的词典打开。
4. 编码由 macSKK 依文件名去猜：名字里带 utf8 的当 UTF-8，其余一概当 EUC-JP。官方词典都是 EUC-JP，一般不必理会。纵是猜错了，点词典旁的 i 按钮亦能手动改之。
5. 词典可拖动排序，排在前头的，自是选字时的先锋。

![macSKK 辞書设置页](/img/skk3.png)

基础词典之外，尚有一批专业词典可叠着用：

- **SKK-JISYO.jinmei**：日本人名
- **SKK-JISYO.geo**：地名
- **SKK-JISYO.station**：车站、线路名
- **SKK-JISYO.propernoun**：演艺、企业、动画等固有词
- **SKK-JISYO.law**：法律用语
- **SKK-JISYO.edict**：英和词典，配合后文的 abbrev 模式，敲英出日文

我自己其实只挂了 L 这本，缺什么词便当场录入，个人词典里如今两千二百余条。专业词典随用随加，不必起初就塞满。

而用户登的词存在同一文件夹的 skk-jisyo.utf8 里，纯文本，编辑器打开便能改。换电脑时带走它就是。

## 五、先把假名打出来

罗马字训令式、黑本式等格式都能打。惟几处要留神：

- **ん**：打 nn。后头跟的不是 n 或 y，打一个 n 也行，hanko → はんこ。（个人是习惯打双）
- **促音**：双写下一个辅音，chotto → ちょっと。（格外有节奏感）
- **小写假名**：以 x 起头，xa → ぁ，xtu → っ。有些输入法是用 la，在 SKK 里 l 却是切直接输入的键。新手头一个坑，多半在此。（我自己也踩过）
- **长音**：-，ko-hi- → こーひー。（此自不必多赘墨）

## 六、▽ 到 ▼，正戏开场

### 不带送り仮名的词（亦即汉字词）

大写首字母进 ▽，读音打完按空格变换，再确定。

- Kanji → ▽かんじ
- 空格 → ▼漢字
- 再按空格 → ▼幹事（下一个候补）
- x → 退回上一个候补
- Return → 确定

候补一多，即弹出候补面板，按数字键选字。

其实连确定都可省：径直往下打，上一个词自会落定。（这点恰如先前所提之小鹤音形）

### 带送り仮名的词，SKK 的看家本事

第二个大写字母，意思是「送り仮名从这里起」。按下去，假名一凑齐便自动变换，空格都不必按。

- UgoKu → ▼動く
- UgoKanai → ▼動かない
- OoKii → ▼大きい
- YoMu → ▼読む
- YoNda → ▼読んだ

拆开看 UgoKu：Ugo 是 ▽うご；按 K 那一下，送り仮名的起点便记下了；再按 u，假名凑齐，当即变作 ▼動く。

字典里这一条写作「うごk /動/」，读音后缀添上送り仮名首字的罗马字声母。か・き・く・け・こ 声母都是 k，于是一条正管住了「動か / 動き / 動く / 動け / 動こ」整套五段活用。SKK 命中奇高，其中一点诀尽在此：送り仮名它无须去拆，因为按下 Shift 时业已宣告分节。

### 却有一处例外：サ変動詞

「運動する」这类「名词 + する」，莫把する当送り仮名：

- 对：Undou 空格 suru → 運動する
- 错：UndouSuru

共有词典素来不收这类送りあり条目，UndouSuru 查无此词，会径直跳进登词模式。不过这倒也非常合理——汉字词和する本就无捆绑一说。

### 打错了怎么退

Esc 或 ⌃G：在 ▽ 时是整段弃之；在 ▼ 时是退回 ▽，读音犹存。

## 七、登词、删词、补完

**登词**不必找命令。候补翻到底仍不见要的那个词，macSKK 自动转入登词模式，显出 \[登録：读音\]。此时照常用 SKK 把词拼出来，按 Return，这个词便归入个人的词典中。

备注两条罕用者：

- 登词模式里粘贴用 ⌃Y，⌘V 在此不灵。
- 登带送り仮名的词，只登汉字那一截。UgoKu 进来，只登「動」，莫登「動く」，否则下回会出「動くく」。

**删词**：变换到登错的那个，按 ⇧X（大写 X），确认时打 yes 回车。只删得自己词典里的，避免误删挂载字典词。

**补完**：打读音时，你登过、读音开头相同的词会列在下方，按 Tab 补齐。只对你自己词典里不带送り仮名的词有效。（频繁使用）

登词模式与其认为是报错，毋宁说是 SKK 在成长。用上一段时日，自家词典成形，速度便要越过从前所用之入力。

## 八、不切模式也能打

- **片假名**：▽ 状态下按 q，读音直接变片假名并确定。Katakana → ▽かたかな → q → カタカナ。不必切到カナ再切回来。（外来词常用者必学）
- **abbrev 模式**：かな状态下按 / 进入，此后打的是英文字母，按空格便拿这串字母去查字典。常打的长词可登成两三个字母的缩写；配上 SKK-JISYO.edict，/apple 空格 → 林檎。（常英日夹杂者必学）
- **接头词、接尾词**：用 >。打完「小林」接着按 >，再打 si 空格，候补里基本只剩「氏」「市」，一步到位。（个人不常用）

## 九、小指对策

SKK 唯一公认的短处，乃是 Shift 按得太勤。macSKK 默认带有 Sticky Shift，是以按下分号键也能起效。

- 「有る」：; a ; r u，一次 Shift 不用碰。要打分号本身，则连按两下。

## 速查

### 模式切换

- ⌃J：回かな / 确定
- q：かな ⇄ カナ
- l：直接输入
- L：全角英数
- /：abbrev 模式

### ▽ 读音输入中

- 大写字母：起读音 / 标送り仮名起点
- 空格：变换
- q：转片假名并确定
- Tab：补完
- \>：接头词变换
- Esc / ⌃G：丢掉

### ▼ 变换中

- 空格：下一个候补
- x：上一个候补
- 数字键：在候补面板里选
- Return：确定
- ⇧X：从词典删掉这个候补
- \>：接尾词变换
- Esc / ⌃G：退回 ▽

### 无标记时

- ⇧Q：手动起 ▽
- ;：Sticky Shift
- x + 元音：小写假名
- -：长音
